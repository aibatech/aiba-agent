# Public HTTP and diagnostic privacy boundary

`web_search` and `web_extract` use `security/public_http.py` for their default HTTP transport. Each URL and redirect must resolve exclusively to global public IP addresses. Connections use one validated numeric address directly; HTTPS still verifies the certificate against the original hostname and sends that hostname as SNI. This prevents a second hostname lookup at connection time from bypassing the address check. Empty DNS answers, credentials in URLs, private/mixed DNS answers, excessive redirects, unsupported compression and oversized bodies fail closed.

Limits: five redirects, 2 MiB response body, 25-second network budget. OS DNS resolution itself is outside the socket timeout; no hard DNS-resolution deadline is claimed. Proxy environment variables are intentionally not inherited because proxy-side DNS would bypass the pinning guarantee. Deployments requiring an egress proxy need a separately validated transport; do not disable address validation. Playwright/browser sessions are separate and are not certified by these transport tests.

`tests/test_public_http.py` runs actual validation/redirect/read-loop logic, mocking only DNS and HTTP/socket boundaries. It verifies destination pinning, TLS hostname binding, private redirects, mixed/empty DNS, credentials, body bounds, compression rejection, redirect limits and credential-header minimization. `scripts/certify_web.py` makes a real read-only request to the public AIBA repository and emits status, content digest and predefined outcome criteria. `.github/workflows/live-web.yml` runs it with no service secrets and preserves the report even on failure. One public page is not evidence of general search/research quality.

Metrics now accept only declared counter/gauge names and finite numeric values, with bounded HTTP/task status, method and exception-class labels. Arbitrary labels, request paths and plugin class names are discarded or bucketed; dynamic unknown names collapse to one counter. This prevents owner identifiers in URLs from being copied into metrics and prevents attacker-controlled label cardinality. Existing metric consumers relying on path labels must migrate to the reduced operational schema.

The product bridge now returns a generic field-validation error without Pydantic's submitted input. Owner-facing task data remains private application data and is not silently deleted by this diagnostic change. Audit unknown fields, third-party logs and browser traffic remain separate open certification scopes. No broad Security 10/10 claim follows from these repairs.
